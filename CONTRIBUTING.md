# Contributing

Thank you for improving OpenSiteStack.

1. Discuss material public API or architecture changes before implementing them.
2. Keep the platform site-neutral; do not add real brand content or credentials.
3. Add or update tests for changed behavior.
4. Run `pnpm check` and review the complete diff.
5. Use a focused Conventional Commit message.

By contributing, you agree that your contribution is licensed under MPL-2.0.
