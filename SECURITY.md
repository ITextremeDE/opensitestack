# Security policy

## Supported versions

OpenSiteStack is pre-1.0 software. Security fixes currently target the latest
released version only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory feature in the OpenSiteStack repository. Include affected
versions, impact, reproduction steps, and any suggested mitigation.

Do not include real credentials, personal data, or production data in a report.
